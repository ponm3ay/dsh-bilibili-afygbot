## 术语表（看不懂标题就判不准，先记住这些）

- **队伍缩写**＝三个角色简称连写：`绯洛穗` `爱达千` `清达莫` `露丽莫` `景月露` `心雷穗` `爱琳莫` `龙凤守` `景月莫` `西仇守` `日月守` `秧千穗` `心千穗` …
- **手法记号串**（连写＝一轮循环）：`R`=共鸣解放/大招次数、`E`=共鸣技能、`Z`=重击、`居`=居合、`处`=处决、`开`=从第几轮起手。
  例：`4R26居`＝一轮里 4 次大招＋26 次居合；`5R9处24Z`＝5 大招＋9 处决＋24 重击。
- **分数**：`w`＝万分。`2.42w`＝24200 分，`6.9w`＝69000 分。`S2` / `S2-3` / `S2.3`＝终焉矩阵的赛季与层数。
- **`dps` / `wdps`**：每秒伤害 —— `9.4wdps`＝9.4 万 DPS。**这是圈内硬指标，见到就当强信号。**
- **读秒**：`16.38秒` `16.9s` `25s` `24.8s` 这类 —— 记录一套轴的耗时。**秒数越短越硬**（同队伍比）。
- **`满延` / `延奏` / `互延` / `双延` / `双变`**：延奏系统的手法规格；`满延`＝延奏吃满。
- **`神轴` / `进阶轴` / `标准轴` / `轴分享`**：圈内对"这轴有多狠"的自称 —— `神轴`＞`进阶轴`＞`标准轴`。
- **`全01` / `61` / `31`**＝角色命座（0+1 / 6+1 / 3+1）；`01爱达穗`＝全 0 命 1 精。
- 看懂标题里的 `R/E/Z/居/处` 密度，就能判断这条是不是真手法 —— **记号越密越长，手法越硬**。

## 搜索（每轮至少跑 4 组，优先 `pubdate` 最新）

用设置页里的关键词；没填就用这几组（**12 组，别再少**）——

**A 组·矩阵凹分向**：`鸣潮 矩阵`、`鸣潮 凹分`、`鸣潮 矩阵 出分`、`终焉矩阵`
**B 组·轴/手法向（2026-10-18 主人补）**：`鸣潮 进阶轴`、`鸣潮 满延`、`鸣潮 轴 教学`、`鸣潮 神轴`、`鸣潮 全01`、`鸣潮 循环轴`、`鸣潮 手法教学`

⚠️ **别加"特定配队/角色专属"的词当搜索词**（2026-10-19 主人撤掉 `鸣潮 居合` 的教训）：
`居合` 是绯雪系的专属机制叫法，拿它当关键词会把结果**带偏到单一队伍**，
而且还会撞上完全无关的内容（实测搜出「陶陶居鸣潮联名月饼开箱」）。
关键词要挑**跨配队通用的**（`轴` `满延` `神轴` `全01` `dps` `读秒` 这类）；
`居合` `终夜` `巨剑` `羽` 这种写在术语表里、**用来读懂标题**就够了，不要拿去搜。

⚠️ **B 组是主力补充**：大批「教学轴 / 分享轴」标题里**根本不写"矩阵""凹分"**，而是 `61赞21菲光5r2 5e18终夜`、
`9.4wdps，01绯琳莫25s4居合`、`全01爱达穗16.38秒满延r2巨剑`、`全局8.21wdps，月琳维进阶轴` 这种 **配队＋手法记号＋读秒/DPS** 的写法 ——
A 组搜不到它们。**两组都要跑**，只跑 A 组会漏掉一半内容。
⚠️ **排序用 `pubdate`（最新）**，凹分内容时效极强；同一条关键词可再用 `totalrank` 补一轮看热门。

**⚠️ 时效是硬条件（2026-10-18 主人加）**：搜索时**带上 `within_days=5`**（只返回近 5 天发布的），
例如 `bili_search(keyword='鸣潮 矩阵', num=5, order='pubdate', within_days=5)`。
结果里每条都带 `published`（北京时间）和 `age_days`（距今几天），**挑选前先看一眼**。

## 时效：只收近 5 天（**超过就别发评论**）

| 发布距今 | 处置 |
|---|---|
| **≤ 5 天** | ✅ 正常收；可以发评论 |
| **超过 5 天** | ⚠️ **最多只写进报告，禁止发评论**（已经凉了的视频，@ 主人没有意义，还容易被当挖坟） |

- 判 `age_days` 或 `published` 都行，**别猜**。
- 拿不到时间（`published` 为空）就调 `bili_video_info` 补一次；还是拿不到，**按"超期"处理**，不发评论。
- 例外：`≤5 天` 的视频够多条时，优先发**最新**的那条（`age_days` 最小的）。

## 判定：只要「进阶手法」及以上

分三档，**只看下面这两档值不值得收**：

| 档位 | 特征词 | 处置 |
|---|---|---|
| **轮椅轴**（低） | 轮椅轴、萌新、手残党、无脑、放空大脑、一键、挂机、保姆级、入门、`0 合轴`、`只需1次合轴` | ❌ **一律跳过**（无论多少分） |
| **进阶手法**（收） | 进阶、高阶、多合轴、循环轴演示、逐帧教学、`5R20Z` 这类长记号串、带 `w` 的分数展示 | ✅ 收 |
| **巅峰手法**（优先） | 巅峰、极限、顶分、国服前列、手搓、满合轴、全角色限时循环、`4R26居`/`5R9处` 级密度 | ✅✅ 最优先 |

### 收什么内容（**两种都要收**）

**① 纯凹分展示**（标题形如 `01绯洛穗 4R26居2.42w`、`61爱 31达 5r14e 6.9w`、`「矩阵S2」龙凤守通用1.4w`）——
只要**没带轮椅/萌新标记**，就按进阶档收下。

**② 教学轴 / 分享轴**（**2026-10-18 主人点名补的，别再漏**）——
标题形如：
```
61赞21菲光5r2 5e18终夜 普通玩家已燃尽
9.4wdps，01绯琳莫25s4居合演示
全01爱达穗16.38秒满延r2巨剑
全局8.21wdps，月琳维进阶轴，01月琳维11548分
```
共同特征：**`配队 + 手法记号(5r2/4居合/终夜) + 读秒(25s/16.38秒) + DPS或分数`**。
这是圈内分享「我排的轴怎么打」的标准写法 —— **多半不写"矩阵""凹分"两个字，所以 A 组关键词搜不到**。

判别信号（命中任意两条就收）：
- 标题里有**读秒**（`16.38秒` `24.8s` `25s`）或 **DPS**（`9.4wdps` `8.21wdps`）
- 标题里有**手法记号串**（`5r2` `5e18终夜` `4居合` `5R8羽1苍`）或带**配队名**（`赞菲光` `绯琳莫` `爱达穗` `月琳维`）
- 自称 `神轴` / `进阶轴` / `标准轴` / `轴分享` / `演示` / `流程` / `手法参考`

⚠️ **注意和"轮椅"区分**：如果同时出现 `轮椅` `手残` `无脑` `保姆级` `简化` `简易` `手把手`，
按轮椅档跳过后面的高档位优先 —— 但**要真读内容再判**：有的标题写"简易"其实轴很硬，有的写"进阶"其实是轮椅换皮。
拿不准就看评论区怎么说（`藏私` `教不会` `学不来` 通常说明轴有难度 → 收）。

**明确不要的**：整活、bug 演示、垫分凑数、"一日游"、吐槽/风评/解析类观点视频、纯入门攻略、纯角色评测、
**求助帖**（"我这轴哪儿有问题"）、**赛事直播**、**多队合集/总分排行**。

## 数据落库（**每轮必做，比日报更要紧**）

日报是给人看的；**数据是给工具和别的 agent 吃的**。每条挑中的视频都要追加**一行 JSON** 到
`data/records.jsonl`（家目录下，一行一条，不要写成数组）。

> 为什么值得干：装了本插件的**每台机器**都会通过 `GET /api/bili-duty/v1/...` 对外提供这份库；
> 记录 id 全局唯一（`r_<BV号>_<kinds>`），所以多台机器的数据能按 id 直接合并，不需要中心服务器。

**必填**（缺一条就别写这条记录）：

| 字段 | 取值 |
|---|---|
| `schema` | `"dsh.wuwa/afyg-record@1"`（写死） |
| `id` | `r_<BV号>_<kinds 用-连>`，如 `r_BV1DRJe6wEGc_rotation-score` |
| `kinds` | 记分就写 `["score"]`；抓到文字轴再加 `"rotation"` |
| `source.bvid` / `url` / `title` | 照实 |
| `source.publishedAt` / `ageDays` | 用工具返回的 `published` / `age_days`，**别自己算** |
| `source.up` | `{name, mid, homepage}` —— **homepage 是硬要求**（`https://space.bilibili.com/<mid>`） |
| `score.value` | **纯数字**（`58444`）。标题写没写"分"字都算分 |
| `capturedAt` / `capturedBy` | 时间戳 / `"dsh-bili-scroll/0.1.2"` |

**选填**：

- `team.abbr` —— **只认出来的队名才写**（绯洛穗 / 露丽莫 / 爱琳莫 / 景月露 …）。认不出就留空，**别猜**。
- `rotation` —— **随缘**。简介或评论区里真找到「文字轴 / 蚊子轴 / 蚊子粥」这种记谱才写：
  `{hasText:true, text:"原文照抄", where:"comment|description", evidenceUrl, tokens:[…]}`；
  找不到就整个字段都别写（**没有轴就没有，别硬凑**）。
- `score.mode` 写 `"matrix"`；`score.season` 如 `"S2-3"`；`score.tier` 是轮椅/进阶/巅峰。

**红线**：分数只贴标题里的数字，**不许换算**；抓不到的字段宁可缺，**不许编**。

写法：**单行 JSON**（别 pretty-print），写完 `read` 一眼 `data/records.jsonl` 末尾，**同一个 id 别写第二遍**。

```json
{"schema":"dsh.wuwa/afyg-record@1","id":"r_BV1DRJe6wEGc_rotation-score","kinds":["rotation","score"],"source":{"platform":"bilibili","bvid":"BV1DRJe6wEGc","url":"https://www.bilibili.com/video/BV1DRJe6wEGc","title":"…","publishedAt":"2026-10-17 14:41","ageDays":1.5,"up":{"name":"…","mid":376166553,"homepage":"https://space.bilibili.com/376166553"}},"team":{"abbr":"绯洛穗"},"rotation":{"hasText":true,"text":"蚊子轴↓启动轴：月EQ闪 露RE …","where":"comment","evidenceUrl":"https://www.bilibili.com/video/BV1DRJe6wEGc"},"score":{"value":58444,"unit":"score","raw":"58444","mode":"matrix","season":"S2-3","tier":"peak"},"capturedAt":"2026-10-19T02:15:09+08:00","capturedBy":"dsh-bili-scroll/0.1.2"}
```
